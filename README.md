# Goal: 
A basic app using python that allows rolling dice and saving presets from the terminal. May be ported to Unity if I have time.

# Tech stack: 
Python. import random, math, regex. import sys if saving dice roll presets via text file. If building graphical tool, C# + Unity

# MVP:
Rolls multiple dice (e.g 10d6) quickly
A way to roll one roll (e.g 1d20 + 11) multiple times in an expedient manner (via terminal)
Simple math (e.g 1d20+11-1+1-2) is supported
A way to save “presents” and have them easily accessible to be rolled over and over

# Future Plans:
Graphical interface
Integration of PF2e mechanics such as multiple attack penalty, status effects etc
Integration of DND 5e advantage / fortune effects
